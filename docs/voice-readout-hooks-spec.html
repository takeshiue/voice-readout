🤖 1. Antigravity CLI (agy) フック仕様

agy (Antigravity CLI) は、AIの実行ループ（ツール使用や推論）に合わせて以下の 5種類 のフックを提供しています。
※注意: Claude Codeにあるような SessionStart や SessionEnd といったCLI自体の起動・終了を検知するフックは agy には存在しません。

イベント名 発火タイミング 主な用途・仕様
PreToolUse ツールが実行される直前 コマンドの実行許可/拒否の判定、引数の書き換え、セキュリティ監査など
PostToolUse ツールが実行された直後 ツール実行後のクリーンアップ、ログ保存、結果の自動補正など
PreInvocation AIを呼び出す（推論開始）直前 プロンプトへの追加コンテキスト注入（※当プラグインでは音声のプリウォームに利用）
PostInvocation AIの呼び出し（推論）が完了した直後 出力結果の検査、強制的な継続/停止のコントロールなど
Stop AIの実行ループ終了時（ターン完了時） 最終チェック、完了条件の確認（※当プラグインではここで応答テキストを抽出して読み上げを実行）

⚠️ 二重読み上げ防止（重複登録の注意点）

マージ仕様に関する警告:
Antigravity CLI は ~/.gemini/config/hooks.json（グローバル）と .agents/hooks.json（プロジェクト）の両方を探索し、同一フックをマージして 2回順次実行 します。
2重読み上げを防ぐため、登録は グローバル側（~/.gemini/config/hooks.json）に単一集約 します。

🛡️ 3. 音声長判定と即時ローカルフォールバック仕様

生成されたクラウド音声を安全レンジ（65%〜135%）で厳密にチェックし、異常時は再生成を待たずに破棄してローカル即発話へ切り替えます。

1
想定発話時間 (expected) の正確な計算
expected = 文字数 / (各エンジンの基準速度 × 設定スピード係数)
2
末尾の無音自動トリミング (VAD / ffmpeg)
APIが末尾に付着させた余分な無音（0.3秒以上の沈黙）を即座にカット。
3
上下両側ガード判定（65% 〜 135%）
判定結果 検知された状態 システムの処理
＜ 65%（短すぎる） 通信途切れ・文章欠落 ❌ クラウド音声を即破棄 ➡ ローカルTTSで即発話
65% 〜 135% 正常な音声 ✅ クラウド音声を高音質再生
＞ 135%（長すぎる） 2回繰り返し読み・指示文誤読 ❌ クラウド音声を即破棄 ➡ ローカルTTSで即発話
沈黙ゼロ化のメリット:
異常音声を再生成（5〜10秒待ち）せず、即座に捨ててローカルで鳴らすため、ユーザーの耳に届く音声が一切途切れずスムーズに継続します。
